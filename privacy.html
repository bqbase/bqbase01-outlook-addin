Privacy Policy — BQBase Email Assistant

Last updated 8 September 2026

BQBase Email Assistant is an email drafting assistant. It exists in two forms that share one backend and one policy: an Outlook add-in and a Gmail Chrome extension. This page describes exactly what each one reads, what it sends, and where it goes.

What it reads

Only when you open the assistant panel, and only from the message you have open:

  • The subject, body text, and sender of the message currently open.
  • Your own display name and email address, so drafts can be signed with your name instead of a placeholder.
  • Anything you type into the assistant's chat box.
  • Files you explicitly attach, by dragging them onto the panel or using "Browse for file". Nothing is read from your device otherwise.

It does not read your mailbox, your folders, your contacts, other messages, or any page other than the mail client you opened it in.

Where it is sent

The above is sent to a Cloudflare Worker operated by BQBase, which adds an API credential and forwards the request to OpenRouter, which routes it to the language model openai/gpt-5.6-luna to produce a reply. The model's response comes back the same way.

Cloudflare and OpenRouter process this traffic under their own privacy policies, as does the model provider OpenRouter routes to.

What is stored

  • The clients store nothing. The Chrome extension declares no storage permission. The chat transcript lives only in the open panel and is gone when you close it.
  • The Worker stores and logs nothing. It does not write message content anywhere. The only thing it holds is a short-lived, in-memory count of recent requests per IP address, used to rate-limit abuse; it is not persisted and is lost when the instance ends.
  • No API key is stored in either client. The credential lives only as an encrypted secret on the Worker.

What is not done

  • No analytics, telemetry, tracking pixels, or advertising.
  • No data is sold, rented, or shared with anyone outside the processing chain described above.
  • No data is used to train models by BQBase.
  • Nothing is read or sent unless you open the panel and send a message.

Your control

Removing the extension or add-in ends all access immediately. Because nothing is stored, there is no retained data to delete.

Please note: the content of emails you ask the assistant about is sent to a third-party language model. Do not use it on messages whose contents you are not permitted to disclose to an external service.
