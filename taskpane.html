Your API key is stored in your Outlook account's roaming add-in settings (syncs across your own devices) and is sent directly from your browser to your chosen provider's API — never to any server this add-in's developer operates. Microsoft's own documentation notes roaming settings are not encrypted secure storage, so treat this the way you'd treat any key saved in a browser: don't use this on a shared/public computer.
